QuickLinks Installation Guide
1. Unzip the file, or if you haven't, download it from the main page.
2. Go to chrome://extensions and enable Developer Mode on the top right.
3. Click Load Unpacked on the top left and select the unzipped QuickLinks folder that you previously downloaded.
4. You are done! There should be a pinned button near the puzzle piece icon on the top right of Chrome. If you have not enabled it, enable it.

"How do I add my links?"
1. Press the QuickLinks icon.
2. Click add your first website and follow the instructions.
3. There you go!
